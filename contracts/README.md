# Machine contracts

JSON Schema Draft 2020-12 for extraction citations, private quiz sets, Reviewer verdict and orchestration state. Validate formats as well as types. Server semantic checks supplement the schemas: end ≥ start, citation hashes/locators resolve, owner/scope/concepts match, questions cover critical ideas and include recall/explain/apply, unique question IDs, Reviewer evidence supports completion and uncertainty cannot complete. Never trust a schema-valid but unsupported citation/verdict. Quiz sets are private; public session DTOs strip expected_answer. Reviewer correctness maps to nullable ProgressEvent correct (uncertain null), while partial is non-correct but stores a separate label; calibration excludes unresolved null events and reports matched sample count.

Revision 2 adds language-registry.json, language-support.schema.json and initial unverified docs/language-support.json, plus link-source.schema.json for typed managed Drive source snapshots. Language statuses require proof per capability; unique/complete locale set enforced semantically. Link descriptor validates source type, HTTPS/safe source access, kind-specific paragraph or timestamp fields, original citation resolver and owner/Collection in application code; schema acceptance alone does not authorize ingestion/folder writes.

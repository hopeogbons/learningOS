# Chapter 3 — Atoms and electron arrangement

## Atomic number
The atomic number equals the number of protons in an atom's nucleus. A neutral atom has the same number of electrons as protons.

## Isotopes
Isotopes of one element have the same proton count and different neutron counts. Their mass numbers differ because mass number is protons plus neutrons.

## Electron shells
Electrons occupy energy levels. Outer-shell electrons are called valence electrons and help explain bonding behavior.

## Electron configuration
A configuration records occupied orbitals, such as 1s2 2s2 2p6 for a ten-electron atom. Orbitals fill according to energy and occupancy rules; the notation itself is not a shell diagram.

## Ions
An ion forms when an atom gains or loses electrons. Losing one electron makes the net charge one unit more positive; gaining one makes it one unit more negative.

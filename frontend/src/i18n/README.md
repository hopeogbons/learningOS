# Learning OS localization

The ordered registry uses the user's ten screenshot languages. Catalogs contain 258 same-key interface messages per locale, authored for the specific supplied Learning OS workflows. Material titles, original source excerpts, citation IDs, chemistry/formula/code text and user names are data and are deliberately not translated by the UI message layer.

`I18nProvider` is a React client context embedded by the Next.js server layout. The layout reads `learningos_locale` before rendering `lang` and `dir`. The three separate nonsecret preferences are UI locale, study locale, and BCP 47 speech locale. `setLocale` changes only UI locale; profile can change each preference separately. `setPreferences` changes cookies and delegates account PATCH to the application's authenticated persistence callback. `restorePreferences` hydrates saved account preferences without writing them back and avoids discarding a choice made during the initial account read.

`intl-messageformat` 10.7.18 implements ICU MessageFormat with native `Intl` cardinal/number rules. Missing keys throw a visible implementation error rather than silently showing English. ICU placeholders match across locales. English and the inflected target languages use real plural forms for material/collection/section/concept/attempt counts; Chinese, Japanese and Indonesian use grammatically invariant forms. Arabic includes zero, one, two, few, many, and other. Russian includes one, few, many and other. UI strings are plain text and cannot inject markup.

`fonts.css` retains Inter first, then a locale-specific Noto Arabic/Simplified Chinese/Japanese fallback. Fonts are local, unicode-range-subset WOFF2 files, loaded only when relevant glyphs occur. They are the 400-weight font assets; browsers synthesize stronger emphasis. `public/fonts/PROVENANCE.json` records exact source packages, versions, tarball URLs and registry integrity hashes verified before extraction. OFL licenses accompany each family. No font request to an external CDN is necessary.

Verification: `python scripts/check_locales.py` checks all keys against the UI inventory, literal component references, interpolated variables by the supported ICU AST parser, nine representative numeric values including fractional values, Arabic/Russian plural branches, all ten registry options, native script retention, local font metadata/WOFF2 assets/licenses and font subset coverage of catalog glyphs. `--report` prints synthetic-only metadata and a long-string fixture. Browser zoom/mobile/drawer/RTL screenshots are a separate gate. The pseudo-long fixture must be used in a real browser before claiming it passes layout checks.

Translation review status: all ten catalogs have been reviewed during authoring for workflow meaning, consistent terms, original-source preservation, truthful Local/Drive status, microphone denial and speech-unavailable fallback; these are machine-authored translation candidates. A proficient/native reviewer has not yet approved them. German and Russian expansion, Arabic RTL and mixed Latin/citation content, Chinese Simplified and Japanese glyphs need browser review. Catalog coverage does not verify live study model quality or any spoken language. L03 native semantic assessment and L04 per-language actual STT/TTS remain separate connected-release prerequisites. User-visible browser/server capability checks must show typing fallback where speech is unavailable.
